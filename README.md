# 车行记

一款免费、简洁的安卓车辆数据记录工具，帮助比亚迪车主（就是我）查看车辆的里程与能耗变化。

## 下载

[点击下载最新版本](https://github.com/YX002/chexingji/releases/latest)

打开后，在页面的 Assets 中选择 `.apk` 文件下载安装。

目前支持 Android 15 及更高版本（更低版本未经过测试，不代表不能使用）。

## 功能

- 采集车辆里程、电量、能耗、胎压等页面信息。
- 按日、周、月查看用车记录。
- 查看行程日历、充电统计、估算电费和续航达成率。
- 支持 CSV/TXT 历史数据导入及 CSV 备份导出。
- 提供多种柔和配色。

## 使用前请留意

1. 请先安装并登录比亚迪 App，选择正确的车辆，并保证比亚迪App打开时的界面为车辆信息页。
2. 采集功能需要开启无障碍权限，用于读取车辆页面和操作页面入口；本工具不提供车辆控制功能。
3. 定时自动采集需要手机亮屏且已解锁，后台限制或官方 App 页面变化可能导致采集失败。首次配置后请先测试。
4. 本工具无法自动补回未采集的历史记录。
5. 能耗、电费、充电次数和续航达成率等统计仅供个人用车参考。
6. 当前版本记录保存在本机，不上传至开发者服务器。卸载、清除数据或换机前，请先导出备份。
7. 请在安全场景下使用，驾驶过程中不要操作手机。
